ENAble

When we note that an axis is enabled, it really means that the stepper motor on that axis is enabled. With stepper motors, the motor for an axis can be enabled or not.

ENA

No

Yes

Axis is Enabled
An axis must be enabled for Rosetta to drive the motor, making the motor rotate its shaft.

When performing indexing operations, it is recommended to leave the axis enabled between indexing movements. This helps ensure there is no movement before the next indexing operation.

There is a configuration setting which is related to this. Axis Not Enabled can be set to warn the user if the a needed axis is not enabled, or to automatically enable the needed axes.

ENA

Yes

No

Axis is not Enabled
When an axis is not enabled, the motor’s shaft can be turned by hand. This is a useful option if there is a hand wheel used to position the cutter manually. An example of this is for cross slides and curvilinear slides.

This setting allows the axis to be automatically enabled whenever needed.

If an axis is automatically enabled for use, it is not un-enabled when the operation completes. Un-enabling the axis must be done manually.

Within the Settings program, the Axis Selection tab can be used to make an axis availlable for use.
