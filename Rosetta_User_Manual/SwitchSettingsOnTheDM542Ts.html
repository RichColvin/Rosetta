DIP Switch Settings on the DM542T Stepper Motor Drives

Rosetta uses DM542T Stepper Motor Drivers to make the stepper motors work. There is one for each channel inside the Rosetta case. These DM542Ts can have different configurations (DIP Switch Settings) set on them based on your needs.

Notes

  1. Before opening the cover on the Rosetta box, ensure it is powered off and the power cable removed. This will help ensure you are not shocked.
  2. Do not change the 5V/24V switch on the side of the DM542T. If it is set to 24V, the channel will not work correctly to make your stepper motor work.
  3. Do not touch any components inside the box which have exposed places. Static electricity in your body can damage the electrical components.

Stepper Motor Current (Amps)

Depending on the stepper motor you are driving, you also may want to adjust the current being delivered to the motor. Some testing has shown that setting it too high can cause your stepper motor to heat up quite a bit. It probably won't overheat, but it can get quite hot. In particular, NEMA 17 stepper motors generally do not need as much current as NEMA 23 stepper motors. You can set the value closer to what is needed if you wish.

Do note that setting it too low can cause the stepper motor to not work as expected. So test the values selected before committing a new setting for work on a prized piece.

To change the current setting, you can change the values for the selected channel on the DM542 Stepper Motor Drive. Those switches are SW1 - SW3, and the value options are listed on page 6 in the User Manual for the DM542T.

Changes to this will probably require changes to the scale settings for a device on the Axis and Stepper Motor Tuning tab of the Settings program.

Idle Current

We recommend you leave this at 50%. (That is SW4 set to off).

Microsteps per Revolution

When you run the program, Microstep Calculator, to identify the micro steps per revolution you want to use, you can change the values for the selected channel on the DM542 Stepper Motor Drive.

As noted there,

  • Higher microsteps per revolution: this gives more granularity of movement, though something below 0.0005” is probably not noticeable.
  • Lower microsteps per revolution: this allows the stepper motor to run faster. This may be desired if you want to quickly move the position of the cutter or the object before engaging the cutter into the workpiece.

Those switches are SW5 - SW8, and the value options are listed on page 6 in the User Manual for the DM542T.
