What's New in Rosetta

This page lists what is new in each version of the Rosetta software, with the newest version at the top. When you update your system, you get every change listed here, up to the newest version.

Which version do I have?

Your version is shown at the top of the main screen, under Rosetta, and at the top of each page of the Rosetta Settings program. It looks like this:

O/S 1.0 Beta 1.3 - 04 November 2026

Note: The date is when that version was released, so a version listed below with a later date is newer than yours. To get it, update your system.

O/S 1.0 Beta 1.12 - 17 November 2026

What’s New

  • Geometric Chuck Designer - a software geometric chuck. Set up to 5 stages, see the pattern they make, and save it as a G-code program that cuts it on the face with C and X. Presets give classic patterns to start from. Find it under Applications > Rosetta.
  • Check Circle - a button in both the Geometric Chuck Designer and the Rosette Designer. It saves a small program that draws a circle round C's axis, so you can set the cutter at the right starting radius by measuring the circle (see Setting the Start Radius).
  • Shut Down - at the bottom of the Applications menu, and the red power symbol on the bar at the bottom of the screen. It shuts the computer down properly before you switch the power off (see Switching the System Off).

What’s Changed

  • Rosette Designer, Ellipse: set by A (half its length) and B (half its width) under Ellipse Parameters. A second rocking rosette can ride on the ellipse, in its own column, with its lobes spaced evenly along the ellipse's outline and a Phase that slides the pattern along it.
  • Rosette Designer, Phase: given as a percentage of a lobe (50% is half a lobe) instead of a fraction.
  • Rosette Designer: "Advance and Retract" is now Advance and Retract Cutter.
  • Backup Rosetta and Update Rosetta are no longer on the desktop - use the Applications menu (click on the arrow to the right of Rosetta). Rosetta and Rosetta Settings stay on the desktop.

What’s Fixed

  • Rosette Designer, rosette on an ellipse: the note under the drawings now gives the right radius to start the cutter when the pattern starts on a wave's deepest point (for example a D rosette at Phase 0%). Started at A, the waves came out past the ellipse.

O/S 1.0 - (date TBD)

The original version of the Rosetta software. Everything described in this manual is part of this version.
