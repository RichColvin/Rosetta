Home All Axes (Ctrl-Home)

To home all axes, there are three options:

  1. Press the Ctrl and Home keys simultaneously on the keyboard
  2. Select Machine | Homing | Home All Axes from the menu bar.
  3. Use Home All Axes on the F3 Manual Control / Jogging screen

To home an individual axis,

  1. Select Machine | Homing | Home Axis (axis)

Rosetta does not use homing switches, so homing an axis simply sets its current position as its home (zero) position. Position the axis where you want home to be before homing it. (Limit switches are not used for homing.)
