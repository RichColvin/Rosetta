Rosetta was developed by ornamental turners for use with a rose engine.

It is designed to provide the ornamental turner a way for synchronizing activities on the rose engine using stepper motors, in a manner which also assists the ornamental turner with reducing the workload for onerous tasks.

Design goals

We designed Rosetta to provide the ornamental turner with the ability to:

  1. Execute relatively simple movements using menu options.
  2. Remove the mundane tasks from the ornamental turner’s activities, increasing the likelihood that the final product will have fewer errors. An example is adding a turk’s head design onto the end of a piece, and skipping every 3rd index.
  3. Implement more complex designs using standard gCode (such as software simulation of rosettes or a geometric chuck).

We designed Rosetta to be one which:

  1. Is powerful enough to
    1. Drive simultaneous movement on up to 10 axes ①,② (AKA, channels), each of which can be set to any of:
      • 2 spindles
        • Traditional spindle (Sp0)
        • Rosette phaser/multiplier (Sp1)
      • Linear axes: X, Z, U, V, or W
      • Rotary axes: A, B, or C
    2. Handle inputs from up to 6 limit switches
    3. Accommodate the use of an E-Stop button
    4. Use a signal tower with 2 lights and a siren to help the user monitor long-running activities (and alert the user when things go awry).
  2. Can control complex movement using standard gCode.
  3. Is integrated with the devices provided by ornamental turning vendors.
  4. Can have the software upgraded easily by the user as new functionality becomes available.

Rosetta is more than the software or the hardware

The ornamental turner needs a system which is not just powerful, but which has a set of tools surrounding it to make it functionally easy to use. To that end, there are additional pieces which have been provided.

Designed with the ornamental turner in mind

The system configuration files are developed around the needs of an ornamental turner using a rose engine. These functions are not typical for such control systems, but have been implemented on Rosetta.

Online user manual

There is an on-line user manual which will be continually updated.

And a user forum

There is an on-line user forum where users can share information.

Based on Debian Linux, but easy to use


Turk’s head
Though it is based on Debian Linux, the user interface has been customized so that the usage of the system will be very intuitive (you only need to double click on the Turk's head icon on the desktop). If you know how to use Linux, that's OK, but it is not required to use the system.
Note: The Rosetta emblem is a Turk’s head - a pattern cut with an eccentric cutting frame. (See also, ECF on Flat Surfaces in the Ornamental Turning Book of Knowledge.)

Supports very complex work using gCode

Rosetta is an implementation of LinuxCNC, and thusly it allows for the use of standard gCode. The LinuxCNC gCode language is based on the U.S. National Institute of Standards and Technology’s RS274/NGC language, and is also outlined in the International Organization for Standardization’s standard, ISO 6983-1. You do not need to study those; instead there is a gcode quick reference to help you if you choose to go this path.
We are providing an online library for gCode programs developed by ornamental turners, allowing for re-use of the code by other ornamental turners. The intent is that the gCode will be documented in such a way that users can easily take a bit of gCode and modify it as needed for their own needs. This library will continue to grow over time.

OT equipment vendor support

We are working with vendors of ornamental turning hardware to have their parts designed for use with Rosetta. For example, a curvilinear slide could come with a stepper motor attached, and also have the necessary jack to plug it into Rosetta.
We have also architected the configuration files so that updated files can be supplied by the vendors when they supply the hardware (e.g., a new definition for the Z axis could be supplied with the curvilinear slide, ensuring that the configuration works as expected).

A system for now ... and the future

Rosetta’s software can be upgraded using an easy mouse click from the Applications menu. And unlike many annoying systems we had at work, this system will not constantly harass you to upgrade; and the upgrades will not take many hours to complete.
We selected vendors for all the components (especially the cabling) which show reliability for being around for a while, and supplying quality parts at reasonable prices.

Buy it off-the-shelf

We want Rosetta to be one which can be purchased as a completed system, needing no user design nor development. Just plug it in and go.
And we are designing it so that you can expand as your needs grow. The Expansion Box② can be added later if you find the Base Box① does not support enough axes of movement.

What are some examples of how it can be used?

Some examples of the way Rosetta can be used include:

  • Run the rose engine as a typical machine:
    • Spindle by itself,
    • Rosette phaser/multiplier (RPM) by itself, or
    • Spindle and RPM together (which can be at different speeds).
  • Index one of the axes of movement:
    • Spindle by itself,
    • RPM by itself (i.e., phasing the rosette relative to the object, as would be done when using a crossing wheel),
    • Spindle and RPM together,
    • Any linear axis (X, Z, U, V, or W), or
    • Any rotary / angular axis (A, B, or C).
  • Coordinate the movement of any of the axes, or make other complex movements possible, through the use of gCode (e.g., a software simulation of a geometric chuck).
  • Add threads to an object with many advanced options available but not required.
  • Using the Rosette Designer, the ornamental turner can use emulate the use of an actual, physical rosette to confirm the design imparted meets their artistic goals. And then, the designed rosette can be exported for 3D printing or machining.

What is Rosetta not designed to do?

Rosetta is not intended to be used to replace the ornamental turner. It is not a system built to enable the user to develop a complete design, load it into Rosetta, and then press GO.

We believe that workmanship at risk③ makes for the most beautiful products.

Certainly, a user could develop a sufficiently complex gCode program which would do all the work for the user, making it work similarly to what is done for 3D printing or a CNC woodworking router. But even that has risk in the ornamental turning world. Wood is a natural material, and the opportunity for a problem is ever present. An operator needs to be managing the process, not leaving it to a computer.

But more importantly, the process of ornamental turning should be fun. Rosetta is designed to help you with that journey.

Why is LinuxCNC being used?

LinuxCNC ...

  1. Can be configured to meet the design goals needed for use on a rose engine, without having to develop a set of programs which may be difficult to support later.
  2. Is powerful enough to handle the design goals we established for Rosetta.
  3. Has been around for many years, having been initially designed by the U.S. National Institute of Standards and Technology in 1993. It has a strong user community with good support. And it continues to be upgraded to provide support needed for new computing hardware.
  4. Continues to support the same basic ideas and interfaces as it has for years, and it does not require the user to re-learn the system each time it is upgraded.
  5. Runs on a very stable and powerful operating system (which also does not require relearning to use when upgraded).
  6. Uses off-the-shelf, readily available parts.
  7. Does not have a high license cost to get started, nor a high maintenance cost for continued use.

All this provides for a system which can meet the current needs at a reasonable cost, and provide for good long-term support.

What is the underlying technology being used?

Rosetta uses:

  1. LinuxCNC, an open-source system which runs on Debian Linux.
    • Linux is an operating system which runs on general purpose computers like a PC or Raspberry Pi.
  2. A Raspberry Pi 5, which is a powerful, low cost, general-purpose computer. The Raspberry Pi 5 has shown it is powerful enough for the computations needed to make LinuxCNC run smoothly.
  3. Readily available, off-the-shelf parts:
    • Mesa 7i92TH Programmable I/O Card
    • Stepper Online DM542T Stepper Motor Drivers
    • Standard computer monitor
    • Standard computer keyboard and mouse
  4. A custom printed circuit board (PCB), developed to make the wiring of the system easier, faster, and more reliable.

Notes

  1. The Base Box supports
    • 6 channels (axes)
    • 3 limit switches
    • 1 E-stop button
    • a signal tower with two lights and a siren
  2. The Expansion Box adds capabilities for
    • 4 channels (axes)
    • 3 limit switches
  3. Workmanship at risk is an idea outlined by David Pye in his book, “The Nature and Art of Workmanship”.
