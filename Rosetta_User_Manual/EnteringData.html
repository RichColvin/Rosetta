Entering Data

Whenever you want to change a value in the Rosetta screens, keep these thoughts in mind:

  • You must have your mouse over the data field to type in a new value
  • You must depress the Enter key after entering any data for the system to accept that you have entered a new value.

These are all a function of the programming system we used for the display panels (and this is the most advanced programming system available).
