Backing Up Key User Files to a USB Flash Drive

The Back Up to USB program copies your own Rosetta files onto a USB flash drive plugged into the Raspberry Pi. Each backup goes into its own dated folder, so earlier backups on the flash drive are never overwritten.

To copy a backup back onto the Raspberry Pi - for example after replacing its memory card - see Restoring Key User Files from a USB Flash Drive.

What Gets Copied

These are the files which get backed up to a USB flash drive when this program gets run.

Note: hidden files (names starting with a period) are not copied.

Settings

Your settings, and any settings files you have exported get backed up.

Files Folder on the USB Flash Drive
/home/reuben/Documents/*.ini Documents

Key Note:

  1. Settings files (*.ini) saved in other directories are not backed up by this program.

Gcode Programs

Your gcode programs in the default directory.

Files Folder on the USB Flash Drive
/home/reuben/linuxcnc/configs/Rosetta/gcode/*.* gcode

Key Note:

  1. Gcode programs in sub-directories of this folder are backed up. However, gcode programs in other directories are not backed up by this program.

HAL Additions

Your own HAL additions and your tool table.

Files Folder on the USB Flash Drive
/home/reuben/linuxcnc/configs/Rosetta/Rosetta_Custom/Rosetta_Custom.hal

/home/reuben/linuxcnc/configs/Rosetta/Rosetta_Custom/Rosetta_Tool.tbl

Rosetta_Custom

Key Note:

  1. If these files are saved in other directories, they are not backed up by this program.

Your Subroutines and User M-codes

Your own subroutines and user M-codes in LinuxCNC's nc_files directory.

Files Folder on the USB Flash Drive
/home/reuben/linuxcnc/nc_files/*.* nc_files

Key Note:

  1. If these files are saved in other directories, they are not backed up by this program.

Backing up the Rosetta Settings files

To back up these files, there are 2 options.

Option 1: Use the Applications menu

  1. Click on Applications at the top left corner of the screen
  2. Click on the arrow to the right of Rosetta
  3. Click on Backup Rosetta

Option 2: Use the File menu in Rosetta Settings

  1. Open the Rosetta Settings program.
  2. Click on File at the top left corner of the Rosetta Settings window.
  3. Click on Back Up to USB...

The same Back Up to USB window opens. When you close it, you are back in Rosetta Settings.

Note: Rosetta Settings cannot be run while LinuxCNC is running, so this option is only there when LinuxCNC is closed.

After the backup finishes: the USB flash drive is ejected

When the backup finishes, Rosetta ejects the USB flash drive. Ejecting means the Raspberry Pi has finished with the flash drive and has disconnected from it, so that it is safe to pull out. The flash drive is still plugged in, but the Raspberry Pi can no longer use it: it no longer shows in the File Manager, or in the Back Up to USB or Restore from USB windows.

  • Do not pull the USB flash drive out while the backup is running. Wait until Rosetta says It is now safe to remove the USB stick.

To use the USB flash drive again - for example, to make another backup, to restore a backup, or to copy a gcode program from it - you have to take it out and put it back in:

  1. Pull the USB flash drive out of the Raspberry Pi.
  2. Wait about 5 seconds.
  3. Plug the USB flash drive back into the Raspberry Pi.
  4. Wait a few seconds for the Raspberry Pi to find it. A File Manager window may open showing what is on the flash drive; you can close that window.

The USB flash drive can now be used again.

Note: If Rosetta says The stick could not be ejected automatically, eject it yourself before pulling it out: open the File Manager, and in the list on the left side of its window, click the eject symbol (⏏) next to the USB flash drive's name. When the flash drive's name disappears from the list, it is safe to pull it out.
