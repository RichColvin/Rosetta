Threading - Single Start

Purpose

This gCode is used to establish threads on a piece.

Code

; Make single-start threads
; The value of Z is the distance to cut the threads (in this case, 0.25 inches)
; The value of K should be 1/TPI (in this case, 16 TPI = 0.0625)
G33 Z0.25 K0.0625
;
; If the cross slide is connected to X also, these codes can reposition the cutter back to the beginning position.
; Move the cutter along the X axis out from the threads (towards the user) by 0.5 inches
G0 X0.5
; Move the cutter along the Z axis in the opposite direction of the threading by 0.25 inches
G0 Z-0.25
; Move the cutter along the X axis to put it back into place
G0 X-0.5

Code Comments

G33 is only used for single-start threads. For multi-start threads, G76 is needed.
